# 验收测试用例

> 实验名称：开源个人博客系统二次开发
> 测试日期：2026-09-07
> 测试环境：Windows 11 / Node.js 22 LTS / Ghost 5.x / SQLite

## 测试概述

本文件记录验收测试用例，覆盖功能测试、权限测试、主题/界面测试和恢复测试四大类，共计18个测试用例。

## 一、功能测试（8项）

### TC-F01：会员注册成功
- 前置条件：Ghost实例已启动，会员功能已启用
- 测试步骤：访问首页 → 点击注册 → 输入有效邮箱和密码 → 提交
- 期望结果：注册成功，会员账号出现在管理端会员列表
- 实际结果：通过

### TC-F02：会员登录成功/失败
- 成功场景：输入正确邮箱密码 → 登录成功，显示会员名称

### TC-F03：管理员发布文章
- 前置条件：管理员已登录管理端

- 期望结果：文章发布成功，前台首页可见，文章详情页可访问
- 实际结果：通过

### TC-F04：文章编辑与更新
- 测试步骤：编辑已有文章 → 修改内容 → 更新
- 期望结果：文章更新成功，前台显示更新后内容
- 实际结果：通过

### TC-F05：标签关联与浏览
- 测试步骤：点击文章标签 → 进入标签页 → 查看文章列表
- 期望结果：标签页显示标签信息，文章列表仅显示该标签下文章
- 实际结果：通过

### TC-F06：会员评论提交
- 前置条件：会员已登录，评论功能已启用
- 测试步骤：进入文章 → 滚动到评论区 → 输入评论 → 提交
- 期望结果：评论提交成功，显示在评论区，管理端可见
- 实际结果：通过

### TC-F07：关键词搜索命中

- 实际结果：通过

### TC-F08：搜索无结果提示
