## 1. 选型决策

本实验选择 Ghost 路线，而非 RealWorld 规范路线。

**选择理由：** Ghost是成熟产品级系统，有完整的编辑器、会员、评论、搜索；聚焦主题和扩展，不重写基础能力；直接体验二次开发而非从零开发。

| 组件 | 版本 |
|---|---|
| Ghost | 5.x |
| Node.js | 22 LTS |
| Ghost CLI | 1.x |
| SQLite | 3.x |
| 自定义主题 | 1.0.0 |

## 4. 风险评估

| 风险 | 影响 | 应对措施 |
|---|---|---|
| Node.js版本不兼容 | 高 | 使用Node 22 LTS |
| 端口2368被占用 | 中 | 安装前检查端口 |
| 主题兼容性问题 | 中 | 使用gscan检查 |
| 搜索中文表现不佳 | 中 | 补充搜索高亮和标签过滤 |
| 数据丢失 | 高 | 定期导出备份 |

## 5. 验收场景（6条）

1. 新用户访问博客，可以浏览文章列表和详情，无需登录
2. 访客可以注册成为会员，使用邮箱和密码登录
3. 管理员可以发布带标签的文章，文章在前台可见
4. 登录会员可以在文章下发表评论，评论对其他访客可见
5. 用户可以通过搜索框输入中文关键词找到相关文章
6. 系统重启后，所有文章、评论和会员数据仍然存在
