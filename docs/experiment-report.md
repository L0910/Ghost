## 一、需求分析

### 实验背景
个人博客系统包含身份认证、内容管理、分类标签、评论互动和全文检索等典型Web子系统。本实验以成熟开源项目Ghost为基线，完成可辨识的二次开发、功能测试、Git版本管理和现场运行展示。

### 实验目标
1. 能够从GitHub README、Release和许可证中判断开源博客方案的适用边界
2. 掌握Ghost本地实例的安装、启动、停止、数据备份方法
3. 能够定位主题、Content API、标签和评论相关模块，完成可见的二次开发
4. 完成注册/登录、文章、标签、评论和搜索主流程的功能测试
5. 掌握用Issue、Feature Branch、Pull Request管理增量开发的方法

### 功能需求
- 本地Ghost实例可启动，前台和管理端可访问
- 管理员和普通会员两类账号，普通会员可以登录
- 可创建、编辑并发布文章，文章至少关联一个标签
- 前台可以浏览文章详情并提交评论
- 可以按关键词搜索文章
- 自定义主题，视觉修改与功能修改均可在源码中定位
- 至少一项自主扩展功能并提供测试

## 二、架构设计

### 技术选型
| 组件 | 选择 | 理由 |
|---|---|---|
| 基线项目 | Ghost 5.x | 成熟的内容与会员博客平台，MIT许可证 |
| 运行时 | Node.js 22 LTS | 符合Ghost兼容矩阵 |
| 数据库 | SQLite 3 | 本地开发轻量级 |
| 主题模板 | Handlebars | Ghost官方模板引擎 |
| 前端 | 原生CSS + JavaScript | 无框架依赖，轻量高效 |

### 系统架构
系统采用"核心不变，主题扩展"的架构策略：
- Ghost核心：负责认证、内容、标签、会员、评论等基础能力，不做修改
- 自定义主题：负责页面展示、交互逻辑和自主扩展功能
- Content API：主题通过Ghost内置助手访问内容数据
- SQLite数据库：持久化存储所有业务数据

## 三、实现细节

### 自定义主题开发（oss-blog-theme v1.0.0）

**修改的组件：**
1. 导航栏：添加搜索按钮、会员登录/注册入口、滚动效果
2. 文章列表卡片：卡片式设计、悬停上浮、标签角标、作者头像、阅读时间
3. 文章详情页：居中标题、特色图、自动文章目录、作者信息卡片、相关推荐
4. 搜索功能：弹窗式界面、实时搜索结果、热门标签推荐、无结果提示、键盘可访问
5. 404页面：友好错误提示、搜索入口、推荐文章

### 自主扩展功能

#### 功能一：相关文章推荐
- 用户价值：帮助读者发现相关内容，提升阅读深度和站点停留时间
- 实现方式：文章详情页底部添加推荐模块，基于当前文章主标签匹配同标签下其他文章
- 数据来源：Ghost内置{{#get}}助手，通过Content API查询
- 可配置：推荐数量（3/4/6篇），可在主题设置中调整
- 隐私影响：纯服务端渲染，不收集用户数据

#### 功能二：搜索高亮与导航
- 用户价值：从搜索结果进入文章后，快速定位关键词位置，提升阅读效率
- 实现方式：纯前端JavaScript，从URL参数读取关键词，遍历文本节点高亮
- 功能：高亮匹配、上一个/下一个导航、键盘快捷键（F3/Ctrl+G）、关闭高亮
- 数据来源：URL参数 ?s=、?search=、?q=
- 隐私影响：纯浏览器端处理，不发送数据到服务器

### 其他体验优化
- 文章目录（TOC）自动生成
- 回到顶部按钮
- 图片懒加载
- 响应式布局（桌面/移动端适配）
- 无障碍支持（高对比模式、减少动画偏好、键盘导航）

## 六、问题与反思

### 遇到的问题
1. Ghost源码仓库 vs 运行时：克隆的是完整开发版monorepo，需要Docker才能运行开发环境。解决方式：聚焦主题开发，主题可独立打包安装到任意Ghost实例。
2. 中文搜索效果：Ghost原生搜索对中文支持有限。解决方式：在主题层补充搜索高亮和标签过滤。
3. 主题兼容性：Ghost主题有严格的模板要求。解决方式：使用gscan工具进行兼容性检查。

### 实验收获
1. 理解了开源软件的二次开发模式：不修改核心代码，通过主题、插件、API等扩展点进行定制
2. 掌握了Ghost主题开发技能：Handlebars模板语法、Ghost助手使用、主题结构
3. 实践了Git工作流：Feature Branch、Conventional Commits、Pull Request
4. 体会了测试的重要性：通过系统化测试用例设计，发现边界场景问题

### 后续改进方向
1. 服务端搜索增强：接入Elasticsearch或MeiliSearch实现更强大的全文检索
2. 评论系统增强：添加评论点赞、回复、@提及等功能
3. 文章数据分析：为作者添加浏览趋势、评论数等数据概览
4. 多语言支持：添加中英文界面切换功能
5. PWA支持：添加离线访问和推送通知能力
