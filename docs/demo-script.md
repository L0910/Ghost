# 课堂演示脚本

> 演示时长：5-10分钟
> 演示环境：本地Ghost实例
> 演示日期：2026-09-07

## 演示流程

### 第一步：项目介绍（1分钟）
- 项目解决什么实际问题：个人博客系统，支持内容创作、会员互动和内容检索
- 使用了哪个开源项目：Ghost（https://github.com/TryGhost/Ghost），MIT许可证
- 固定版本：Ghost 5.x / Node.js 22 LTS / SQLite 3
- 个人仓库：https://github.com/L0910/Ghost

### 第二步：基线与二次开发对比（1分钟）
- 原项目基线：Ghost默认Casper主题，基础博客功能
- 本人修改的模块：
  1. 自定义主题oss-blog-theme（全部前端展示层）
  2. 相关文章推荐功能（文章详情页底部）
  3. 搜索高亮与导航功能（前端JS增强）
  4. 文章目录自动生成、回到顶部等体验优化

### 第三步：Live Demo - 会员搜索与登录（2分钟）
1. 访问 http://localhost:2368 前台首页
2. 点击导航栏"搜索"按钮，展示搜索弹窗
3. 输入中文关键词"开源"，展示实时搜索结果（标题、摘要、标签、作者、日期，关键词高亮）
4. 点击搜索结果，进入文章详情页（URL带?s=参数，页面关键词高亮，顶部导航工具栏）
5. 点击"登录"按钮，使用会员账号登录（member_a@example.com / Member@123456）

### 第四步：Live Demo - 管理员发布文章（1.5分钟）
1. 访问 http://localhost:2368/ghost 管理端，管理员登录
2. 新建文章，输入标题和正文，添加标签"实验"和"演示"
3. 点击发布，返回前台验证新文章出现在列表中
4. 进入文章详情页，展示文章内容、标签、文章目录、相关推荐

### 第五步：Live Demo - 会员评论与权限（1分钟）
1. 会员登录状态下，进入文章，发表评论
2. 退出登录（匿名状态），刷新页面，展示评论区：匿名可浏览但不可评论
3. 尝试直接访问/ghost管理端，展示匿名用户被重定向

### 第六步：自主功能展示与代码说明（1.5分钟）
1. 进入有标签的文章详情页，滚动到底部，展示"相关推荐"模块
2. 在文章URL后添加 ?s=Ghost，展示关键词高亮和导航工具栏
3. 打开代码编辑器，展示核心代码：related-posts.hbs 和 search-highlight.js
4. 展示测试文档 tests/acceptance.md 中的相关测试用例

### 第七步：Git证据与备份说明（1分钟）
1. 打开GitHub仓库页面，展示提交历史（git log --oneline --graph）
2. 展示Pull Request（feature/blog-enhancement → main）
3. 说明数据备份：管理端导出内容，数据库文件位置，重启后数据保留

## 离线预案

- 本地运行：Ghost实例完全本地运行，不依赖外部网络
- GitHub展示：提前截图仓库页面、提交历史、PR页面
- 代码展示：本地用VS Code打开项目，直接展示代码
- 图片资源：所有演示文章使用本地图片，不依赖外部CDN

## 常见问题预案

| 问题 | 应对方案 |
|---|---|
| Ghost实例启动失败 | 运行ghost doctor检查，查看日志ghost log |
| 端口2368被占用 | 停止占用进程，或修改Ghost配置端口 |
| 主题不显示 | 管理端确认主题已激活，清除浏览器缓存 |
| 搜索无结果 | 确认Content API已启用，检查文章是否已发布 |
| 评论功能不显示 | 管理端设置中确认会员和评论功能已启用 |
| 相关推荐不显示 | 确认文章有关联标签，且同标签下有其他文章 |
| 搜索高亮不生效 | 确认URL中有?s=参数，关键词在页面中存在 |
